# harness-skill-compare

Use for a substantive comparison of skill triggers, behavior or curation choices. Scale narrow overlap questions to the relevant branches.

**Boundary:** Compares skills' triggers, behaviour and curation choices in depth as evidence; it records no decision (harness-evaluate) and scans no harness (harness-scan).

<!-- registry:generated traits -->
- `scale-to-question`: Scale comparison depth to the question — descriptions and relevant branches for a narrow overlap, every shipped instruction, metadata and script for a full comparison.
- `inspected-vs-executed`: Distinguish inspected code from executed behaviour and never infer invocation frequency from description text.
- `registry-consult`: Consult the registry index, skill records and reference pages for classification and prior decisions.
- `skill-review-file`: For a durable merge, upgrade or rebuild decision, write a dated skill review file that opens with the compared set and that a later ruling cites as evidence.
- `component-inventory`: Cite each behavioural component — step, gate, template, rule, heuristic or red-flag table — with file and line, treating a heading as not a component.
- `presence-matrix`: Tabulate one row per component and one column per skill, marking present, variant or absent, and explain how each varying row is realised and which is stronger.
- `verdict`: Conclude whether the skills substitute or complement, stating what to take, from where, and what to leave, each with a reason.
- `narrow-stays-in-chat`: Keep a narrow comparison in chat with no file, stating its coverage and any unverified behaviour.
