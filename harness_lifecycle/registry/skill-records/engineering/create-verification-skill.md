# create-verification-skill

Use for /create-verification-skill when a project has no scripted way to drive its real app; updating an existing verify skill is maintain-verification-skill, and proving one change on its surface needs no new skill. Generates a project skill that launches the real app, drives a feature as a user would and keeps proof, with a starter feature map, then runs it once end to end.

**Boundary:** Generates a project skill that launches and drives the real app with a starter feature map, and proves it once; our own instructions are authoring-for-agents, running a project's invariant checks is check-invariants, and keeping a generated verify skill current is maintain-verification-skill.
