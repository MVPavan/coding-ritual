# Questionnaire layout

Load when drafting a questionnaire for an absent respondent. Save it as the
skill says; saving it does not send it.

Fill this layout. Group questions into themes, most important theme and question
first, one idea per question. Add a one-line why under a question only where it
could be misread or invite a throwaway answer; leave the rest bare.

```markdown
# <Topic>: questions for <role>

**Purpose:** <the decision or fact these answers settle, in one sentence>
**From** <who asks> **to** <role or name> **· used for** <what the answers feed>
**Please reply by** <deadline> **· about** <rough effort, such as 15 minutes>

## Context

<What the respondent needs to know to answer, and nothing they already know.>

## How to answer

Write under each question. Partial answers and "don't know" are welcome: say how
sure you are rather than skipping a question.

## <Theme 1>

1. <Question>
   _Why it matters: <only where needed>_
   > Answer:

2. <Question>
   > Answer:

## <Theme 2>

3. <Question>
   > Answer:

## Anything else

Is there anything we did not ask that we should know?
> Answer:
```

Estimate the effort from the questions. When the present user has not given a
deadline, ask for it with the other missing recipient context.
